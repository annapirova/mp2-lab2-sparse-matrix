Лабораторная работа 2. Разреженные матрицы.

Порядок действий:
1. Сделать fork
2. Клонировать на компьютер репозиторий с подмодулями:
git clone --recurse-submodules <ссылка на репозиторий>
ИЛИ 
git clone <ссылка на репозиторий>
git submodule update --init --recursive
3. Открываем папку с репозиторием в Visual Studio / VS Code
4. Создаем папку для бинарников, конфигурируем:
mkdir build
cmake ..
5. Собираем командной строкой: 
cmake --build .
ИЛИ
cmake --build . --config Release
ИЛИ 
В Visual Studio выбираем, какой файл запускать, зеленой кнопкой.


Задание:
1. Необходимо дописать в класс недостающие функции:
- умножение матрицы на вектор
- сложение двух матриц
- транспонирование 
- сравнение двух матриц (нужно для тестов)
- умножение двух разреженных матриц (если успеете)

2. Написать на все функции тесты.
